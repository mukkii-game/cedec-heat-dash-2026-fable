# RETRO-CROSS

2026年7月22日〜24日、酷暑のみなとみらい。ゲームクリエイター「ミナト」が、
みなとみらい駅からパシフィコ横浜のCEDEC会場まで走り抜ける、
レトロドット絵の熱走ランアクション。

3日分の道のりを1本の通しステージとして繋げ、WAVE1〜3のチェックポイントで
曲・背景・レベルデザインが切り替わっていく構成です。

**[プレイする](https://retrocross.netlify.app/)** ／ ローカル起動は下記参照。

## 遊び方

- **移動**: ↑↓ / W・S（アナログに前後移動。奥は日陰が多く安全、手前は日向で速いが熱い）
- **加速 / 減速**: → / D でダッシュ（ヒートが上がる速さが若干上乗せされるが、区間を速く抜ける
  ので日向の総被熱はそれでも少なくて済む）、← / A でブレーキ（ヒートのレートは変わらないが、
  日陰に長く留まれるので回復量が増える）
- **ジャンプ**: Space / Z / X / Enter / マウス左クリック（速度が乗っているほど遠くへ跳べる。ただし踏切りで少し減速）
- **ポーズ**: Esc / P　**ミュート**: M　**リトライ**: R（プレイ中いつでも即リスタート）

スマホは左半分のドラッグで移動＋加減速、右半分タップでジャンプ。
縦持ちでは画面下部に専用のタッチパッド（↑↓ / DASH・SLOW / JUMP）が出ます。

体を焼く**ヒートゲージ**が0〜100%の間で上下し、主人公の頭上に数値表示されるほか、
体も足元から徐々に赤く染まっていきます。日向やダッシュで上昇し、日陰・ミスト・
コンビニ「スズシヤ」で下降。日陰にいる間は体全体に涼しげな青いミストがかかります。
**ゲームオーバーはありません。** ヒートゲージが100%（熱中症）になると、巨大な
レッドブルー缶（朱×青ストライプ）を担いだ救助のお姉さんが駆けつけてヒートを全回復
させてくれますが、その間タイムをロスします。誰でも必ずクリアできますが、
タイムロスの少なさがクリアタイム＝★1〜3評価に直結するので、約2分の通しで
ベストを目指してください。ヒートゲージはWAVEをまたいでもリセットされず、
そのまま持ち越されます。

道中にはレッドブルー缶を使った障害物もあります。プレイヤーとほぼ同サイズの缶が
丸太転がしのように横倒しでグルグル回転しながら接近してくるので、ジャンプか
上下移動で回避してください。

## ローカルで起動する

```bash
npm install
npm run dev
```

`http://localhost:5173` を開いてください。

### ビルド

```bash
npm run build
npm run preview
```

```bash
npx playwright install chromium
npm test
```

## 公開

現在の公開先は **[https://retrocross.netlify.app/](https://retrocross.netlify.app/)**
（Netlifyに `npm run build` の `dist/` を直接デプロイしたもの。GitHubとは連携していない
単発デプロイのため、更新する場合は再度 `dist/` をNetlifyの管理画面からアップロードし直す
必要がある）。恒久的な公開先は別途 itch.io 等へ移す予定。

リポジトリには GitHub Pages 用のワークフロー（`.github/workflows/deploy.yml`）も同梱して
おり、Settings → Pages → Source を「GitHub Actions」に設定して `main` ブランチへ push
すれば自動ビルド・デプロイもできる（ただしこちらは現状プレイ用の告知はしていない）。

## 技術構成

- Vite + TypeScript、依存ゼロの自作Canvas 2Dエンジン
- 全グラフィックはコード内で手続き生成したドット絵（480×270内部解像度）
- BGM・効果音はすべて Web Audio API による自作シンセ／ステップシーケンサ
- 日本語表示は [Yusei Magic](https://github.com/tanukifont/YuseiMagic) フォントを同梱（詳細は [THIRD_PARTY_ASSETS.md](THIRD_PARTY_ASSETS.md)）

詳しい設計意図は [GAME_DESIGN.md](GAME_DESIGN.md)、アート方針は [ART_DIRECTION.md](ART_DIRECTION.md) を参照してください。
